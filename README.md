# git_test_demo

A tiny C project used for testing git workflows.

## Layout

- `src/` — implementation sources
- `inc/` — public headers
- `tests/` — unit tests
- `scripts/` — build and test helpers
- `docs/` — notes and documentation

## Build

```sh
sh scripts/build.sh
```

## Test

```sh
sh scripts/test.sh
```
